# AI Collaboration Prompts · Challenge 02 · Pendulum

> Copy the prompts below into your AI assistant (ChatGPT / Claude / Doubao / DeepSeek),
> and it becomes your personal tutor for Challenge 02.

## Full prompt (copy it all at once)

```
I'm working through Challenge 02: Pendulum in the "Build Your Own Physics" repository.

[My background] Starting from zero. I've finished the Python and physics basics in Challenges 00-01 (so I have the Challenge 01 experience).

[Physics goal] Understand: simple harmonic motion, energy conservation, why the Euler method makes energy drift, and how the Euler-Cromer method fixes it.

[Your task] Be my physics tutor, and follow these rules strictly:
1. Explain concepts with everyday examples; save the formulas for last
2. Guide me to write the code myself; never hand me the complete answer
3. Give me a hint for only one TODO at a time
4. When I get something wrong, let me find the mistake myself first (hints, not answers)
5. Only give me the reference answer after I've been stuck for 15+ minutes
6. At the end of each stage, ask me questions to check my understanding
7. Communicate in English

[Current stage] Start by helping me understand the core concepts, then guide me through writing the simulation code.

[My code so far] (paste your code)
```

## Stage-by-stage prompts

### Stage 1: Understand the core concepts

```
Explain the core physics concept of this challenge using everyday examples:
Why does this phenomenon happen? What's the intuition behind it?
```

### Stage 2: Write the simulation

```
I'm about to write the simulation for this challenge. Here's my plan: [your plan].
Ask me 3 guiding questions first — don't give me the code.
```

### Stage 3: Check against theory

```
My simulation outputs X, and the theoretical value is Y.
Why is there a gap? What makes the error shrink?
```

### Stage 4: Test my understanding

```
Quiz me with 5 questions on the core physics concepts of this challenge (no code questions).
For anything I get wrong, explain it with an everyday example.
```

## Debugging prompt

```
My simulation output is wrong: [paste your code and the bad output].

Use Socratic questioning to guide me to the bug myself:
ask one question at a time, and wait for my answer before the next one.
Don't just tell me what's wrong.
```

## Going deeper after you finish

```
My simulation now passes the acceptance criteria.
Give me 3 variation exercises of increasing difficulty to deepen my understanding.
```

## Remember

- ✅ Let AI explain, guide, and question you
- ❌ Don't let AI write it for you or hand you the answer
- If you can't explain every line of the code you submitted to the AI, you haven't learned anything
