# Challenge 09 · Electromagnetism — 验收标准（SPEC）

> 本文件定义挑战 09 的可自动化验收标准。verify.py 据此评分。


## 接口

| 函数 | 签名 | 返回 |
|------|------|------|
| `fdtd_1d` | `(nz=400, dz=1e-3, dt=None, n_steps=1000, source="gauss", eps_r_profile=None, source_idx=None, f_source=2e9)` | `(ez_hist, hy_hist, z)` |

- 物理：一维无源麦克斯韦方程（Ez/Hy 偏振），Yee 交错网格。
- 稳定条件（CFL）：`c·Δt/Δz ≤ 1`，默认取 `0.95`。
- 常量：`C0 = 3e8`，`MU0 = 4πe-7`，`EPS0 = 1/(μ₀c²)`。
- 边界：一阶 Mur 吸收边界（代码已给出，抑制边界反射）。

## 验收项

### S9.1 接口
- 返回 `(ez_hist, hy_hist, z)`，形状匹配 `(n_steps, nz)`。

### S9.2 真空波速 = c
- 高斯脉冲峰值位置随时间移动。
- **验收**：测量波速与 `c` 的偏差 `< 2%`。（`v = Δz_peak / (Δt_步数·dt)`）

### S9.3 介质界面 · 反射存在 + 相位反转
- 界面：`z ≥ 1.2 m` 处 `εr = 4`，其余真空。源在 `z = 0.3 m`。
- 在界面左侧 `z = 1.0 m` 观测：入射脉冲与界面反射脉冲在**时间上分离**。
- **验收 1（反射存在）**：反射时间窗能量 `> 3×` 无界面基准（同一窗口，保证确实有反射）。
- **验收 2（相位反转）**：反射主峰 `< 0`。
  - 物理依据：`Z = √(μ/ε)`，ε 增大 → Z 减小 → 反射系数 `(Z₁-Z₂)/(Z₁+Z₂) < 0` → 反射波相位反转。这是"从高阻抗到低阻抗反射反转"的电磁学核心结论。

### S9.4 介质中波速 = c/√εr
- 透射波在 `z = 1.4 m`（界面后 200 格）的到达时间。
- **验收**：测量波速与 `c/2` 偏差 `< 12%`。（`√4 = 2`，波速减半是折射率定义的直接验证。）

### S9.5 CFL 条件
- `dt = 2·dz/c`（CFL=2），模拟 300 步。
- **验收**：数值爆炸——出现 `NaN` 或 `max|Ez| > 10`。

## 设计说明

- **为什么 Yee 网格是"交错"的**：Ez 与 Hy 在空间/时间上各错半格，差分是中心对称的 → 二阶精度 + 天然满足 `c = 1/√(εμ)`。
- **反射测量用能量比而非幅度比**：FDTD 数值色散会让脉冲产生振荡尾，能量判据比单点幅度更稳健。
- **相位反转是硬核物理**：`ε` 增大 → 阻抗减小 → 反射反转——这个现象在光学（增透膜、反光涂层）里天天用，用 20 行代码验证它，比背公式深刻得多。
- **教学简化**：Mur 边界不完全吸收（残余 ~1% 反射），所以 S9.3 用"相对无界面基准"判据，而不是绝对反射系数——避免验收被边界伪影干扰。
