# Challenge 10 · Relativity — 验收标准（SPEC）

> 本文件定义挑战 10 的可自动化验收标准。verify.py 据此评分。


## 接口

| 函数 | 签名 | 返回 |
|------|------|------|
| `gamma` | `(v)` | `1/√(1-v²)` |
| `lorentz` | `(event, v)` | 变换后的四元组 |
| `inverse_lorentz` | `(event, v)` | 逆变换四元组 |
| `spacetime_interval` | `(event_a, event_b)` | `s² = (cΔt)² - Δx² - Δy² - Δz²` |
| `time_dilation` | `(Δτ, v)` | `γ·Δτ` |
| `length_contraction` | `(L0, v)` | `L0/γ` |

- 事件用四元组 `(ct, x, y, z)` 表示，`c = 1` 自然单位。
- 速度 `v` 以光速为单位（`0 ≤ v < 1`）。
- 本挑战**不需要 numpy**，纯标准库。

## 验收项

### S10.1 γ 因子
- `γ(0.6) = 1.25`（精确）；`γ(0) = 1`。

### S10.2 时空间隔不变
- 1000 个随机事件（固定随机种子保证可复现），随机 `v ∈ [0, 0.9]`。
- **验收**：`s²` 在洛伦兹变换前后一致（误差 `< 1e-9`）。
- 这是狭义相对论最深的洞见：**间隔是几何量，不随观察者改变**。

### S10.3 光速不变
- 光信号事件 `(ct,x) = (3,3)`（即 `x = ct`）。
- **验收**：对 `v ∈ {0.1, 0.5, 0.9}`，变换后 `x'/ct' = 1`（误差 `< 1e-9`）。

### S10.4 逆变换
- `S → S' → S` 往返后恢复原事件（误差 `< 1e-9`）。

### S10.5 尺缩与钟慢
- `time_dilation(1.0, 0.6) = 1.25`（钟慢，运动时钟变慢）。
- `length_contraction(1.0, 0.6) = 0.8`（尺缩，运动杆变短）。

## 设计说明

- **为什么用 (ct, x, y, z) 而不是 (t, x, y, z)**：c=1 时 ct 与 x 同单位，洛伦兹变换变成"时空旋转"（快速度视角），几何意义一目了然，也避免了单位换算的坑。
- **为什么纯标准库**：相对论不需要数值积分，是纯代数问题——这给学习者一个"没有 numpy 也能做物理"的示范。
- **间隔不变是终极验收**：其他判据（γ、尺缩、钟慢）都可能被"背公式"蒙混，但"任意随机事件的间隔不变"只有真正理解变换结构才能通过。
