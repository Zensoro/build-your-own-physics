# SPEC 03 · Orbit

> 本文件的验收标准可被自动化测试。实现需通过以下全部标准。

## 测试环境

- 语言：Python 3.8+（建议用 NumPy，但非必需）
- 依赖：标准库（`math`）；可视化可选 Matplotlib
- 参数：$\mu = GM = 1.327 \times 10^{20}$ m³/s²（太阳），单位可选 AU/年制

## 约定

本 SPEC 提供两套单位制，任选其一实现：

**SI 制**（直观但数字大）：
- $\mu = 1.327 \times 10^{20}$ m³/s²
- 地球轨道半径 $a = 1.496 \times 10^{11}$ m
- 时间步长 $\Delta t = 3600$ s（1 小时）

**AU-年制**（数字友好，推荐）：
- $\mu = 4\pi^2$ AU³/yr²（开普勒第三定律的方便形式）
- 地球轨道半径 $a = 1.0$ AU
- 时间步长 $\Delta t = 0.001$ yr（≈ 8.76 小时）

> 提示：AU-年制下，地球圆轨道速度恰为 $v = 2\pi$ AU/yr。

## 验收标准

### S3.1 接口

- [ ] 提供 `simulate(mu, x0, y0, vx0, vy0, dt, n_steps)`，返回 `(xs, ys)`
- [ ] `xs[0] = x0`，`ys[0] = y0`
- [ ] 返回列表长度为 `n_steps + 1`

### S3.2 圆轨道稳定（地球基准）

以地球初始条件（$x_0 = 1.0$ AU，$y_0 = 0$，$v_{x0} = 0$，$v_{y0} = 2\pi$ AU/yr）积分一年（$n = 1000$ 步，$\Delta t = 0.001$ yr）：

- [ ] 轨道半径在 $0.95 \sim 1.05$ AU 之间（未逃逸、未撞太阳）
- [ ] 一年后回到起点附近：$\sqrt{(x_n - x_0)^2 + (y_n - y_0)^2} < 0.05$ AU（轨道闭合）
- [ ] 面积速度恒定：任意两段等长时间内扫过面积之差 < 2%（开普勒第二定律）

### S3.3 椭圆轨道（速度 $0.8 v_{circle}$）

以 $v_{y0} = 0.8 \times 2\pi$ AU/yr 积分：

- [ ] 轨道为椭圆：$\min(r) > 0.3$ AU，$\max(r) < 1.6$ AU，且 $\min(r) < \max(r)$
- [ ] 近日点与远日点之比与能量守恒预测一致（误差 < 10%）

### S3.4 能量守恒（蛙跳法的核心优势）

总能量 $E = \frac{1}{2}v^2 - \mu/r$（单位质量，速度用前向差分 $v = (x_{n+1} - x_n)/\Delta t$ 从位置恢复）：

- [ ] 圆轨道积分 $10^4$ 步后，$\frac{|E_n - E_0|}{|E_0|} < 0.1\%$（圆轨道相位同步，可直接比较首尾）
- [ ] 椭圆轨道（$0.8 v_c$）：能量**振荡幅度有界**——跑 1 年和跑 5 年，$\frac{\max(E) - \min(E)}{|E_0|}$ 基本相同（增长 < 0.5 倍）

> 说明：这是蛙跳法（辛积分器）与欧拉法的分水岭。
> **辛积分器**的能量误差是**有界振荡**（不随时间增长）；欧拉法则**线性漂移**（跑得越久偏得越远）。
> 椭圆轨道周期与模拟时长不对齐，直接比较首尾会混入相位振荡，所以正确判据是"振荡有界"。
> 验证方法：模拟 1 年和 5 年，比较振荡幅度——辛积分器幅度不变，欧拉法幅度翻倍。

### S3.5 开普勒第三定律（进阶）

- [ ] 对 3 个不同轨道半径（如 $a = 0.7, 1.0, 1.5$ AU）模拟，测得周期 $T$，验证 $T^2 / a^3$ 常数（偏差 < 2%）
- [ ] （可选）绘制 $\log T$ vs $\log a$ 图，斜率为 $3/2$

### S3.6 逃逸速度（直觉检验）

- [ ] $v_{y0} = \sqrt{2} \times v_{circle}$ 时，轨道**不闭合**：一年后 $r > 2$ AU 且仍在增大
- [ ] $v_{y0} = 1.5 \times v_{circle}$ 时，明确逃逸（$r$ 单调增大）
