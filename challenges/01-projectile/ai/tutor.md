# AI 协作提示词 · 挑战 01 · 抛体运动

> 复制以下提示词给你的 AI 助手（ChatGPT / Claude / 豆包 / DeepSeek），
> 它就会变成你挑战 01 的私人导师。

## 完整提示词（一次复制）

```
我在学 "Build Your Own Physics" 仓库的挑战 01：抛体运动（Projectile Motion）。

【我的背景】零基础 / 刚开始学 Python，只会变量、循环、列表、函数、画图（挑战 00 的水平）。

【物理目标】理解：位置、速度、加速度的关系；为什么 45° 角抛得最远；欧拉法是什么。

【任务】请做我的物理导师，严格遵循：
1. 用生活例子解释概念，公式放最后
2. 引导我自己写代码，绝不直接给完整答案
3. 一次只给我一个 TODO 的提示
4. 我写错时，先让我自己找错（给提示不给答案）
5. 我卡住 15 分钟以上，才给参考答案
6. 每阶段结束用提问检验我的理解
7. 用中文交流

【当前阶段】先帮我理解"欧拉法"，然后引导我写抛体模拟的循环部分。

【我目前的代码】（贴你的代码）
```

## 分阶段提示词

### 阶段 1：理解欧拉法

```
用生活例子解释"欧拉法"：
为什么"位置 = 位置 + 速度 × 时间步长"能模拟运动？
误差从哪来？（提示：一步之内速度其实在变）
```

### 阶段 2：写循环

```
我要写抛体的循环部分，这是我的思路：[你的思路]。
先问我 3 个问题引导我，不要直接给代码。
```

### 阶段 3：验证理论

```
我的模拟射程是 X 米，理论值是 254.8 米。
为什么有差距？误差随什么减小？
```

### 阶段 4：检验理解

```
请用 5 个问题考我抛体运动的物理（不要考代码）：
- 为什么 45° 最远？
- 欧拉法误差从哪来？
- 如果把 dt 减半，误差会怎样？
```

## 调试专用提示词

```
我的抛体模拟输出不对：[贴代码和错误输出]。

请用苏格拉底式提问引导我自己找到 bug：
一次只问一个问题，我回答后你再问下一个。
不要直接告诉我错在哪。
```

## 完成后深化

```
我的抛体模拟已经通过验收（射程误差 < 2%）。
请给我 3 个变式练习，难度递增：
1. 加空气阻力（F = -kv²）
2. 地面有高度（从 10 米高台抛出）
3. 月球上抛（g = 1.62）
```

## 记住

- ✅ 让 AI 解释、引导、提问
- ❌ 让 AI 代写、直接给答案
- 如果你无法向 AI 解释你提交的每一行代码，你就没有学到东西
