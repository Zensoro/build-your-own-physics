# Challenge 05 · Wave Machine — 验收标准（SPEC）

> 本文件定义挑战 05 的可自动化验收标准。verify.py 据此评分。

## 接口

| 函数 | 签名 | 返回 |
|------|------|------|
| `simulate` | `(u0, c=1.0, dx=0.01, dt=0.005, n_steps=2000, bc="fixed")` | `(u_hist, x)`：`u_hist` 形状 `(n_steps+1, nx)`，`x` 形状 `(nx,)` |

- 物理：一维波动方程 `∂²u/∂t² = c²∂²u/∂x²`，蛙跳（FTCS）时间格式。
- 初始速度为零（`u¹ = u⁰ + 0.5·C²·∇²u⁰`，`C = c·dt/dx`）。
- 边界：`bc="fixed"` 固定端（`u=0`），`bc="free"` 自由端（`∂u/∂x=0`）。
- 稳定条件：`C = c·dt/dx ≤ 1`（CFL）。

## 验收项

### S5.1 接口
- 返回 `(u_hist, x)`，帧数 = `n_steps + 1`，`len(x) = nx`。

### S5.2 高斯波包分裂传播
- 初始：中心高斯波包（`x0=2.0`, 宽 `0.15`, 区间 `[0,4]`, 400 点）。
- 模拟 `dt=0.005, n_steps=150`。
- **验收**：中心位移衰减到 `< 0.4×` 初始峰值（能量分到两侧）；左右两半区均出现 `> 0.3×` 初始峰值的波峰（分裂成两个波包）。

### S5.3 波速 = c
- 同一模拟。右行波峰应位于 `x0 + c·t = 2.75`。
- **验收**：实测右行波峰与理论值误差 `< 15%`。

### S5.4 边界反射相位
- 波包靠近右边界（`x0=3.4`）向右传播 200 步，足够到达边界并反射。
- 固定端：边界全程 `u=0`；反射后边界内侧点出现**负峰**（相位反转，`min < -0.1`）。
- 自由端：边界满足 `u[-1]=u[-2]`；反射后边界内侧点**不出现明显负值**（同相，`min > -0.05`）。

### S5.5 CFL 条件
- `c=1, dx=0.01, dt=0.03` → `C=3 > 1`，模拟 200 步。
- **验收**：`max|u| > 5`（数值发散 = 不满足稳定条件时格式爆炸）。

## 设计说明

- **为什么用蛙跳格式**：波动方程是双曲型，需要两个时间层；蛙跳格式在 CFL 条件下稳定且无色散。
- **初始速度为零的 u¹**：用泰勒展开 `u¹ ≈ u⁰ + 0.5·C²·∇²u⁰`，避免单独引入初始速度，减少一个坑。
- **相位反转是物理本质**：固定端反射相位反转（波峰变波谷）、自由端同相——这是弦乐器和风管乐器发声差异的根源，也是验收的核心物理现象。
