# AI 协作提示词 · 挑战 05 · 波动方程（Wave Machine）

> 复制以下提示词给你的 AI 助手（ChatGPT / Claude / 豆包 / DeepSeek），
> 它就会变成你挑战 05 的私人导师。

## 完整提示词（一次复制）

```
我在学 "Build Your Own Physics" 仓库的挑战 05：波动方程（Wave Machine）。

【我的背景】零基础起步，已完成挑战 00-04 的 Python 和物理基础（数组 + 挑战 04 的经验）。

【物理目标】理解：理解波动方程、波速、驻波、干涉、边界反射、CFL 稳定性条件。

【任务】请做我的物理导师，严格遵循：
1. 用生活例子解释概念，公式放最后
2. 引导我自己写代码，绝不直接给完整答案
3. 一次只给我一个 TODO 的提示
4. 我写错时，先让我自己找错（给提示不给答案）
5. 我卡住 15 分钟以上，才给参考答案
6. 每阶段结束用提问检验我的理解
7. 用中文交流

【当前阶段】先帮我理解核心概念，然后引导我写模拟代码。

【我目前的代码】（贴你的代码）
```

## 分阶段提示词

### 阶段 1：理解核心概念

```
用生活例子解释本挑战的核心物理概念：
为什么这个现象会发生？直觉是什么？
```

### 阶段 2：写模拟

```
我要写本挑战的模拟，这是我的思路：[你的思路]。
先问我 3 个问题引导我，不要直接给代码。
```

### 阶段 3：验证理论

```
我的模拟输出是 X，理论值是 Y。
为什么有差距？误差随什么减小？
```

### 阶段 4：检验理解

```
请用 5 个问题考我本挑战的核心物理概念（不要考代码）。
我答错的地方，用生活例子解释。
```

## 调试专用提示词

```
我的模拟输出不对：[贴代码和错误输出]。

请用苏格拉底式提问引导我自己找到 bug：
一次只问一个问题，我回答后你再问下一个。
不要直接告诉我错在哪。
```

## 完成后深化

```
我的模拟已经通过验收。
请给我 3 个变式练习，难度递增，让我深化理解。
```

## 记住

- ✅ 让 AI 解释、引导、提问
- ❌ 让 AI 代写、直接给答案
- 如果你无法向 AI 解释你提交的每一行代码，你就没有学到东西

## 验收

写完后运行 `python starter/verify.py` 自动验收。全部通过再对照 `solutions/` 参考实现。
