## How to Propose a Challenge

Open an issue using this template:

```
**Title**: [Challenge Idea] Challenge Name

**Physics Topic**: One sentence describing it

**Why it's worth doing**: What understanding will learners gain?

**Difficulty**: ★ to ★★★★★

**Draft Acceptance Criteria**: 3+ automatable criteria

**References**: Textbook chapters / papers / existing implementations
```

## Selection Principles

- **Independently completable**: No lab equipment or private data required.
- **Has an "aha" moment**: On completion, learners will marvel, "So that's how it works."
- **Educational value**: Fills a gap left by the existing 12 challenges.
- **Automatable acceptance**: The SPEC must be runnable.
