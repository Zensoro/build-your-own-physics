## 如何提一个挑战

在 issue 中按这个模板提议：

```
**标题**：[Challenge Idea] 挑战名称

**物理主题**：一句话说明

**为什么值得做**：学习者能获得什么理解？

**难度**：★ 到 ★★★★★

**验收标准草案**：3 条以上可自动化的标准

**参考资源**：教材章节 / 论文 / 现有实现
```

## 挑选原则

- **可独立完成**：不需要实验室设备、私有数据
- **有"啊哈"时刻**：完成时学习者会惊叹"原来如此"
- **教学价值**：填补现有 12 个挑战的空白
- **可自动化验收**：SPEC 能跑

## 高优先级（社区呼声）

1. **Ising Model** — 相变的可视化是最震撼的物理体验之一
2. **Brownian Motion** — 从随机游走理解扩散与爱因斯坦关系
3. **Cellular Automata** — 简单规则涌现复杂行为，物理哲学的绝佳载体

来选一个，做出来，提交 PR！
