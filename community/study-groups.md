# Study Groups — 组队通关，互相 review

> 物理学习最孤独的时刻，是卡在第 7 关的 RK4 上而无人可问。在这里找队友。

## 如何加入/创建学习小组

1. 在 issue 里搜索 "study group"，或新建一个：
   - 标题：`[Study Group] 挑战 01-06 · Python · 每周一次`
   - 说明：语言、时间、时区、目标、你目前的进度
2. 在讨论区（Discussions）发帖找队友
3. 组好后建议用 Discord / 微信群 / QQ 群交流

## 互相 review 的清单

- [ ] 物理正确吗？（能量守恒？符合理论值？）
- [ ] 代码可读吗？（注释讲物理了吗？）
- [ ] 数值稳定吗？（收敛性测试过吗？）
- [ ] 可视化清晰吗？（颜色固定？比例真实？）
- [ ] 换个人能跑起来吗？（README 写清楚了吗？）

## 展示你的作品

- 完成挑战后把代码放进自己的 fork，在 Discussion 里贴出**效果图/GIF**
- 在 GitHub README 的 "Hall of Fame" 里给自己留个位置（有的话）
- 投稿到 [Hall of Fame 征集帖]（维护者会不定期发帖）

## 群组资源

- 共享笔记：项目 Discussion 的 wiki 区
- 问题求助：issue 打上 `question` 标签
- 每周同步：各自 repo 的 issue 里程碑
