# Study Groups — Team Up and Review Each Other

> The loneliest moment in learning physics is getting stuck on Challenge 07's RK4 with no one to ask. Find your teammates here.

## How to Join / Start a Study Group

1. Search issues for "study group", or create a new one:
   - Title: `[Study Group] Challenges 01–06 · Python · Weekly`
   - Description: language, time, timezone, goals, your current progress
2. Post in Discussions to find teammates.
3. Once formed, we recommend Discord / WeChat / QQ groups for day-to-day chat.

## Mutual Review Checklist

- [ ] Is the physics correct? (Conservation of energy? Matches theory?)
- [ ] Is the code readable? (Do the comments explain the physics?)
- [ ] Is it numerically stable? (Convergence tested?)
- [ ] Is the visualization clear? (Fixed colormap? True aspect ratio?)
- [ ] Can someone else run it? (Is the README clear?)

## Show Off Your Work

- After finishing a challenge, put your code in your own fork and post a **screenshot / GIF** in Discussions.
- Claim a spot in the README's "Hall of Fame" (if one exists).
- Submit to the [Hall of Fame thread] (maintainers post periodically).

## Group Resources

- Shared notes: the wiki area of the project's Discussions.
- Ask for help: label your issue with `question`.
- Weekly sync: issue milestones in each member's repo.
