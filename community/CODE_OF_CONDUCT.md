# Code of Conduct

## 我们的承诺

为了营造开放、友好的社区氛围，我们承诺让所有参与者——无论经验水平、教育背景、身份认同如何——都能在不受骚扰的环境中参与本项目。

## 我们的标准

**有利于社区的行为：**

- 使用友好、包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事
- 对其他成员展现同理心

**不可接受的行为：**

- 使用性化语言或图像，或不受欢迎的性关注
- 挑衅、侮辱或贬低性评论，人身攻击
- 公开或私下的骚扰
- 未经明确许可发布他人的私人信息
- 其他在专业环境中合理认定为不当的行为

## 我们的责任

维护者有责任澄清和执行行为标准，并对任何不当行为采取适当、公平的纠正措施。

维护者有权利和责任移除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、issue 等，并会在适当时说明处理理由。

## 适用范围

本行为准则适用于项目所有公共空间，也适用于个人在公共空间代表本项目或社区时的行为。

## 执行

如遇滥用、骚扰或其他不可接受的行为，请私信联系维护者。所有投诉都将被及时、公正地审查和调查。

## 依据

本行为准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，版本 2.1。
