## 推荐的"读法"

```
1. 先读挑战 README 的"物理背景"部分
2. 自己写代码（1-3 天）
3. 卡住时：先看 Hints，再看对应教材章节
4. 完成后：对照 SPEC 自测，再看参考实现
5. 想深入：读经典教材的对应章节
```
