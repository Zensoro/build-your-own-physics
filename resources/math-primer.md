# 零基础数学补给站 — 微积分直觉版

> **你不需要先学会微积分再学物理。你需要的是"够用的直觉"。**
> 本指南用生活语言讲清楚本仓库用到的一切数学。公式是副产品，直觉才是主角。

## 只需要 5 个数学直觉

### 1. 变化率 = 速度（导数的直觉）

"位置变化得多快"就是导数。

```
开车：里程表读数是"位置"，速度表读数是"导数"。
导数 = 你现在这一刻，位置在变多快。
```

- 匀速 10 m/s：每秒位置 +10 米
- 匀加速：速度本身也在变，速度的导数叫加速度

**代码视角**：导数 = 每步的增量 ÷ 每步的时间
```python
# 位置 x 随时间 t 变化
dx = x_new - x_old      # 位置的变化量
dt = t_new - t_old      # 时间的变化量
v = dx / dt             # 速度 = 位置的变化率 = 导数！
```

> 用得上吗？**挑战 01-04 全程在用**，但你不必知道"导数"这个词。

### 2. 累加 = 面积（积分的直觉）

"把很多小片加起来"就是积分。

```
下雨接水：把每分钟的降雨量加起来，就是总水量。
积分 = 把很多小量加起来。
```

**代码视角**：积分 = 累加
```python
# 用很多小步累加出总位移
x = 0.0
for each 时间步:
    x += v * dt    # 每步位移 = 速度 × 时间步长
```

> 用得上吗？**挑战 01 的欧拉法就是积分**。你已经在用积分，只是不知道名字。

### 3. 三角函数 = 转圈圈（sin/cos 的直觉）

```
sin 和 cos 描述"转圈"。
时钟指针的高度 = sin(角度)；指针的横向位置 = cos(角度)。
```

**代码视角**：
```python
import math
math.sin(角度)   # 求角度的正弦
math.cos(角度)   # 求角度的余弦
```

> 用得上吗？**挑战 01（抛体角度）、02（单摆）、03（轨道）** 都用。只需要知道"给角度，返回 0~1 之间的数"。

### 4. 向量 = 带箭头的量（方向 + 大小）

```
速度、力、加速度都是向量：既有大小（多快/多强）又有方向（往哪）。
位置也是向量（x, y 两个数字就能表示一个点）。
```

**代码视角**：向量 = 两个数字
```python
position = (x, y)      # 位置向量
velocity = (vx, vy)    # 速度向量（x 方向 + y 方向）
```

> 用得上吗？**挑战 03 之后全程用**。只需要会"x 分量 + y 分量分开算"。

### 5. 指数增长/衰减 = 复利（e 的直觉）

```
钱存银行，利息再生利息 = 指数增长。
放射性衰变、热传导、波衰减都是指数。
```

**代码视角**：每步乘一个小于 1 的因子
```python
# 指数衰减（比如温度向环境趋近）
T = T + (T_env - T) * 0.01   # 每步向 T_env 靠近 1%
```

> 用得上吗？**挑战 06（热传导）、11（量子隧穿）** 用。只需要知道"乘因子"这个模式。

## 一张图总结：5 个直觉 ↔ 挑战对应

## 遇到不懂的数学怎么办？

1. **先跳过** — 复制代码跑起来，看到现象再说
2. **问 AI** — "用生活例子解释 [概念]，不要公式"
3. **看现象** — 数学是为了解释现象，现象才是主角
