# AI 辅助学习指南 — 让 AI 当你的私人物理导师

> 2026 年学物理的新方式：**人学物理，AI 当陪练。**
> 本指南教你如何用 AI 最大化学习效果，而不是让 AI 替你学习。

## 核心原则：AI 是导师，不是代写

```
✅ 让 AI 解释 → 你理解
✅ 让 AI 引导 → 你自己写出来
✅ 让 AI 提问 → 你检验理解
❌ 让 AI 代写 → 你什么都没学到
```

**黄金法则**：如果你无法向 AI 解释你提交的每一行代码，你就没有学到东西。

## 每个挑战的 AI 工作流

### 阶段 1：理解（10 分钟）

```
把这段物理概念讲给我听：[挑战的物理背景]
用生活例子，不要用公式。然后问我 3 个问题检验我是否听懂。
```

### 阶段 2：写代码（核心，30-60 分钟）

```
我要写 [挑战名] 的模拟，目标：[SPEC 验收标准]。
请当我的导师：
1. 一次只给我一个 TODO 的提示，不要一次讲完
2. 我给代码后，先引导我自己找错，再解释
3. 卡住 15 分钟以上才给参考答案
```

### 阶段 3：看现象（10 分钟）

```
我运行了代码，现象是：[描述或截图]。
这个现象说明了什么物理原理？哪里符合预期？哪里奇怪？
```

### 阶段 4：检验理解（10 分钟）

```
请用 5 个问题考我 [挑战名] 的核心概念。
我答错的地方，用生活例子解释。
```

## 万能提示词模板

```markdown
我在学 "Build Your Own Physics" 仓库的挑战 [NN]：[名称]。

【我的背景】零基础 / 学过一点 Python / 学过物理

【物理目标】[一句话描述要理解什么]

【角色】请做我的物理导师，遵循：
1. 用生活例子解释概念，公式放在最后
2. 引导我自己写代码，绝不直接给完整答案
3. 我写错时，先让我自己找错（给提示不给答案）
4. 每阶段结束用提问检验我的理解
5. 用中文交流

【当前阶段】[理解 / 写代码 / 看现象 / 检验]
```

## 高级技巧

### 1. 让 AI 检查你的理解
```
"用费曼学习法：让我用小学生能听懂的语言解释 [概念]，你检查哪里不清楚。"
```

### 2. 让 AI 帮你 debug（不给答案）
```
"我的代码输出不对（贴代码和错误信息）。
先问我 3 个问题引导我自己找到 bug，不要直接告诉我。"
```

### 3. 让 AI 深化直觉
```
"这个 [模拟现象] 在现实世界中哪里能看到？
给我 3 个生活中的例子。"
```

### 4. 让 AI 出变式练习
```
"给我 3 个 [挑战名] 的变式练习，难度递增。
先从最简单的开始，我做完再给下一个。"
```

### 5. 让 AI 做 Socratic 式提问
```
"不要直接解释 [概念]，用一连串问题引导我自己推导出来。
每回答一步，告诉我对不对，再问下一步。"
```

## 常见误区

| ❌ 错误用法 | ✅ 正确用法 |
|-----------|-----------|
| "帮我写完整的抛体模拟代码" | "引导我写抛体模拟，一次一个提示" |
| "这行代码什么意思？"（复制粘贴） | "我写的这行代码对吗？为什么？" |
| "直接给我答案" | "问我问题，让我自己推出来" |
| 不懂就跳过 | "我卡住了，换个生活例子解释" |

## 为什么 AI 辅助适合零基础？

1. **随叫随到的导师** — 深夜卡住也有人问
2. **无限耐心** — 问一百遍"为什么"也不烦
3. **个性化节奏** — 你慢它就慢，你快它就快
4. **即时反馈** — 写完立刻知道对错

**但记住：AI 是辅助，物理是你自己的。** 当你终于看到自己写出的行星轨道时，那种"我做到了"的成就感，是任何 AI 都无法代劳的。
